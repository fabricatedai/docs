Open source · Apache 2.0

Contribute to Device Connect

Device Connect is an open-source protocol that lets AI agents discover, call, and subscribe to physical devices. Add your device in three steps.

Start on the portal → Read CONTRIBUTING.md
01

Connect your device

STEP 1
Set up
Create a portal account and give AGENTS.md to your coding agent.
STEP 2
Write the driver
Ask the agent to write a thin driver over your existing SDK.
STEP 3
Test from an agent
Discover the device, call a command, and subscribe to an event.

The portal is for testing only. For real data or unreleased products, self-host from the repository.

02

Test with other devices

Device Connect is designed to work across device types, device manufacturers, and fleets. Add devices from other manufacturers to the same account and have one agent operate them together.

Robotics
A component from one maker on a robot from another.
Manufacturing
Machines, robots, and cameras in one work cell.
Labs and test
Instruments from different vendors running one experiment.
Homes and buildings
Devices from different brands responding to one request.
Retail and hospitality
Kiosks, robots, and cameras across many sites.
Vehicles
Sensors, chargers, and in-vehicle devices.
Edge computing
Boards, cameras, and sensors from different vendors.
03

Publish

STEP 1
Push to a public repository
Use Apache 2.0 or another open-source license. Include a README.
STEP 2
Keep credentials out
Add *.creds.json and AGENTS.md to .gitignore before you push.
STEP 3
Open an issue
Open an issue titled Integration: <device name> that links to your repository. You can also include a video that explains your build.

To change the core packages or add an adapter, see CONTRIBUTING.md. Report vulnerabilities as described in SECURITY.md.
